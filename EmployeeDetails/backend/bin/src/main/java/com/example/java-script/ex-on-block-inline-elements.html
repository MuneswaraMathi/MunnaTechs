Block and Inline Elements

Block elements are those that start on a new line and take up the full width available. Examples of block elements include:

  • <div>
  • <h1> to <h6>
  • <p>
  • <ul>
  • <ol>

Ex:

Div2

Inline elements, on the other hand, do not start on a new line and only take up as much width as necessary. Examples of inline elements include:

  • <span>
  • <a>
  • <img>
  • <strong>
  • <em>

Understanding the difference between block and inline elements is crucial for structuring your HTML documents effectively and applying CSS styles appropriately.
